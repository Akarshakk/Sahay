1. ARCHITECTURE OVERVIEW
------------------------
The application follows a "Feature-First" Clean Architecture, powered by Flutter Riverpod for state management. This ensures scalability, testability, and separation of concerns.

Folder Structure:
lib/
├── core/               # Shared utilities, models, themes, and generic widgets
├── features/           # Feature-based modules (Auth, Home, Incidents, Volunteer, etc.)
│   ├── auth/
│   │   ├── data/       # Repositories and Data Sources
│   │   ├── domain/     # (Optional) Pure business logic entities
│   │   └── presentation/# UI (Screens, Widgets) and Logic (Providers/Controllers)
│   └── ...
└── main.dart           # Entry point

Key Principles:
- ProviderScope: Wraps the entire app in `main.dart` to enable Riverpod state management.
- ConsumerWidget: UI components extend `ConsumerWidget` to listen to state changes efficiently.
- Repository Pattern: UI never calls APIs directly; it talks to Controllers/Providers, which talk to Repositories.

B. Role-Based Authentication & Navigation
-----------------------------------------
Logic:
1. User logs in via phone number.
2. `AuthController` verifies credentials (mocked for demo).
3. `LoginScreen` detects the user role (`UserRole.citizen`, `UserRole.volunteer`, `UserRole.authority`).
4. CRITICAL: All roles are now routed to `HomeScreen`, but `HomeScreen` adapts its UI based on the `userRole` passed to it.

```dart

if (role == UserRole.authority) {

```

C. Location Services & Demo Fallback
------------------------------------
Logic:
1. App requests GPS permission.
2. Tries to reverse-geocode coordinates to an address.
3. HANDLING EDGE CASES: If geocoding fails (common on some networks/platforms), we implemented a "Smart Fallback" for demo purposes.

```dart
// lib/core/services/location_service.dart
Future<String> getAddressFromCoordinates(double lat, double lng) async {
  try {
    // Try real geocoding
    List<Placemark> placemarks = await placemarkFromCoordinates(lat, lng);
    return placemarks.first.name;
  } catch (e) {
    // FALLBACK LOGIC
    // If we are in the demo area (Kalyan), return a realistic address instead of error
    if ((lat - 19.24).abs() < 0.1 && (lng - 73.14).abs() < 0.1) {
      return 'Sahay Control HQ, Kalyan West, Maharashtra 421301';
    }
    return '$lat, $lng'; // Last resort
  }
}
```
